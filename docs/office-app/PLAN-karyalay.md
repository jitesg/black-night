## 1. कौन-कौन

| भूमिका | कौन | app | क्या करेगा |
|---|---|---|---|
| **कार्यालय मुंशी (CM)** | थाने का कार्यालय मुंशी | InvestSuite कार्यालय | कागज़ / प्रार्थना पत्र दर्ज करना, अधिकारी को allot करना, स्थिति देखना |
| **हेड मोहर्रिर (HM)** | हेड मोहर्रिर | InvestSuite कार्यालय | CM वाले सारे काम + आगे चलकर **मालगृह** (माल का रजिस्टर) |
| **अधिकारी** | उ0नि0 / निरीक्षक (विवेचक) | InvestSuite (अभी वाला) | allot हुआ काम अपने module में पाना, आख्या लगाना |

## 2. चार काम

### काम 1 — न्यायालय के कागज़ (चरण 1)
**कार्यालय में दर्ज होगा:**
- न्यायालय (चुनें: मा0 उच्च न्यायालय लखनऊ खंडपीठ / इलाहाबाद / जनपद न्यायालय… / अन्य)
- कागज़ का प्रकार: आख्या माँगी / बेल नोटिस / सम्मन / वारंट (NBW) / जमानत / अन्य
- वाद सं0, मु0अ0सं0, धारा, अभियुक्त / पक्षकार का नाम
- प्राप्ति तिथि, **नियत तिथि**
- कागज़ की फ़ोटो / PDF (एक या अधिक)
- टिप्पणी (वैकल्पिक)

**फिर:** "अधिकारी चुनें" → **allot करें**।

**अधिकारी के InvestSuite में:** 🔔 "न्यायालय से नया कागज़ — वाद सं0 … , नियत तिथि …"; न्यायालय module में नया काम **सारे fields भरे हुए**
और फ़ोटो साथ; अंतिम तिथि वाले alert (अभी जैसे — High Court 5/3/1/0 दिन पहले…) अपने आप लगेंगे।

### काम 2 — RL, जनता दर्शन, अन्य प्रार्थना पत्र (चरण 1)
**कार्यालय में दर्ज होगा:**
- कहाँ से आया: RL / जनता दर्शन / IGRS / SP कार्यालय / CO कार्यालय / थाना / अन्य
- संदर्भ / शिकायत सं0, प्राप्ति तिथि, **अंतिम तिथि**
- आवेदक (नाम, पिता/पति, पता, मोबाइल), विपक्षी (वैकल्पिक)
- विषय (छोटा), प्रार्थना पत्र की फ़ोटो / PDF
- टिप्पणी (वैकल्पिक)

**फिर:** अधिकारी चुनें → **दें**।

**अधिकारी के InvestSuite में:** 🔔 + प्रार्थना पत्र module में नया प्रार्थना पत्र, सब भरा हुआ; "रिपोर्ट लगाएं" / "प्रारूप से जोड़ें" पहले जैसे।

### काम 3 — ऊपर से माँगी सूचना (चरण 2)
1. **दर्ज:** किस कार्यालय ने माँगी (SP / ASP / CO / DCRB / अन्य), पत्रांक, क्या माँगा, भेजने की अंतिम तिथि, पत्र की फ़ोटो।
2. **मँगाना:** कार्यालय किन सिपाहियों / अधिकारियों से मँगाए (एक या कई) — हर एक के फ़ोन पर "सूचना चाहिए … तक"।
3. **जवाब:** वे अपने app में जवाब लिखें / फ़ोटो लगाएँ → कार्यालय में "3 में से 2 आए"।
4. **भेजना:** कार्यालय जवाब जोड़कर तैयार करे (एक जगह सब दिखेंगे), भेजे, और दर्ज करे: "भेजी — दिनांक … , किस माध्यम से"।

### काम 4 — ड्यूटी लगाना (चरण 2)
- तारीख, समय से–तक, ड्यूटी का प्रकार (बैंक / पिकेट / गश्त / यातायात / त्योहार / न्यायालय पैरवी / खजाना / अन्य), जगह
- कौन-कौन: सिपाही / मुख्य आरक्षी / होमगार्ड / PRD (सूची से चुनें; हथियार-कारतूस वैकल्पिक)
- जिसकी ड्यूटी लगी उसके फ़ोन पर सूचना; कार्यालय में "आज की ड्यूटी" सूची
- बाद में: इसी से GD की "रवानगी कर्मचारीगण … बेस प्वाइंट …" लाइन अपने आप बन सकती है (रवानगी के नमूने पहले से app में हैं)।

## 2b. सिपाही — 3 काम (मालिक, 2026-11-16)

सिपाही कार्यालय app में ही **"सिपाही" भूमिका** से login करेगा (अपने 6 अंकों के कोड से) — उसे सिर्फ़ अपनी 3 चीज़ें दिखेंगी।

### सिपाही 1 — कार्यालय को सूचनाएँ देना (कार्यालय के काम 3 से जुड़ा)
- 🔔 "SP कार्यालय से सूचना माँगी गयी — हिस्ट्रीशीटरों की सूची — कल तक"
- सिपाही खोलकर देखेगा: क्या माँगा, किस गाँव / हल्के की, अंतिम तिथि, मूल पत्र की फ़ोटो
- जवाब: लिखकर (बोलकर टाइप भी) + फ़ोटो / सूची → **भेजें** → कार्यालय में "आ गया ✓"
- कुछ न हो तो "निल" एक बटन से
- अंतिम तिथि से पहले याद दिलाने वाली सूचना

### सिपाही 2 — अपनी ड्यूटी देखना (कार्यालय के काम 4 से)
- 🔔 "कल 08:00–20:00 — बैंक ड्यूटी, पश्चिमगांव (साथ: हो0गा0 …)"
- "आज / कल / इस हफ़्ते की ड्यूटी" सूची — जगह, समय, साथी, असलहा (हो तो)
- ड्यूटी शुरू होने से पहले याद दिलाना (जैसे 1 घंटा पहले)
- (बाद में, वैकल्पिक) "ड्यूटी पर पहुँचा" बटन — कार्यालय को दिखे

### सिपाही 3 — सम्मन / नोटिस की तामील
1. **कहाँ से आएगा:** कार्यालय न्यायालय का सम्मन / नोटिस (काम 1) **सिपाही को allot** करेगा — अधिकारी की जगह सिपाही चुनकर।
   आगे (मालिक: हाँ): अधिकारी भी अपने InvestSuite से बना 35(3) / 179 नोटिस तामील के लिए सीधे सिपाही को भेज सकेगा।
2. **सिपाही को दिखेगा:** किसके नाम, पता, गाँव, वाद सं0 / मु0अ0सं0, न्यायालय, नियत तिथि, सम्मन की फ़ोटो।
3. **तामील होने पर:** "तामील हुआ" → दिनांक / समय, किसे दिया (स्वयं / परिवार के सदस्य + सम्बन्ध), हस्ताक्षर-प्रति की फ़ोटो
   (वैकल्पिक: जगह का GPS).
4. **न हो पाने पर:** "तामील नहीं हुआ" → कारण चुनें (पता नहीं मिला / व्यक्ति बाहर गया / लेने से इंकार / मकान बंद / अन्य) + टिप्पणी.
5. **कार्यालय को दिखेगा:** तामील हुआ / नहीं हुआ / लंबित — नियत तिथि से पहले लाल चेतावनी; वापस न्यायालय भेजने का निशान।

### सिपाही वाली screens
1. पहली बार: कोड डालें → "बछरावां थाना — आरक्षी राम कुमार" → PIN
2. मुख्य screen: तीन टाइल — **सूचना माँगी (n)** · **मेरी ड्यूटी** · **तामील (n)**
3. हर टाइल की सूची → विवरण → जवाब / तामील दर्ज करें

## 2c. कागज़ का प्रकार — गिनती, फ़िल्टर, अधिकारी-वार (मालिक, 2026-11-16)

**हर कागज़ का एक "प्रकार" ज़रूर चुना जाएगा** (दर्ज करते समय बटन से, बिना प्रकार के सेव नहीं होगा):

| समूह | प्रकार (शुरुआती सूची — कार्यालय बाद में जोड़ / बदल सके) |
|---|---|
| ⚖ न्यायालय | आख्या माँगी · बेल नोटिस · सम्मन · NBW (गैर-जमानती वारंट) · जमानती वारंट · 82/83 (84/85 BNSS) · स्टेटस रिपोर्ट · अन्य |
| 📄 प्रार्थना पत्र | RL · जनता दर्शन · IGRS · SP कार्यालय · CO कार्यालय · थाना · समाधान दिवस · अन्य |

**उसी से:**
1. **गिनती (मुख्य screen):** टाइलों के नीचे "प्रकार अनुसार लंबित" — NBW 6 · जनता दर्शन 4 · RL 3 · सम्मन 2 … (दबाने पर वही सूची).
2. **फ़िल्टर:** सूची में ⚙︎ → प्रकार · स्थिति (लंबित / तिथि निकली / पूरे) · अधिकारी · तारीख (इस हफ़्ते / इस माह / चुनें) — एक साथ कई.
3. **अधिकारी-वार तालिका (नई screen "अधिकारी अनुसार"):** हर अधिकारी की एक पंक्ति, हर प्रकार का एक खाना —
   ```
   अधिकारी            NBW  सम्मन  आख्या  जनता दर्शन  RL   कुल लंबित  तिथि निकली
   उ0नि0 राम सिंह       3     1      2        1        0       7          2
   उ0नि0 जीतेश सिंह     1     0      1        2        1       5          0
   ```
   किसी खाने को दबाएँ → उस अधिकारी के उस प्रकार के लंबित कागज़ों की सूची.
4. **अधिकारी के InvestSuite में भी** प्रकार साथ आएगा (न्यायालय / प्रार्थना पत्र module के अपने प्रकार से मिलाकर), ताकि वहाँ भी
   उसी नाम से फ़िल्टर हो.
5. Database में: `tasks.kind` (समूह: court / petition …) + `tasks.subtype` (प्रकार) — गिनती तुरंत, बिना धीमे हुए.

## 3. हर काम की स्थिति (कार्यालय को दिखेगी)

```
दर्ज ── allot ──► अधिकारी को मिला ──► देखा ──► आख्या लगी / पूरा      (हरा)
                                         └──► लंबित (तिथि बाकी)       (पीला)
                                         └──► तिथि निकल गई            (लाल)
```
- **अधिकारी से सिर्फ़ स्थिति वापस जाएगी** (देखा / आख्या लगी / पूरा + दिनांक)। आख्या का पूरा text, केस डायरी, मुकदमे का डाटा
  **फ़ोन में ही रहेगा**, cloud पर नहीं जाएगा।
- कार्यालय की मुख्य screen: आज आए / लंबित / तिथि निकली — अधिकारी-वार गिनती।

## 4. कार्यालय app की screens (चरण 1)

1. **पहली बार:** थाना जोड़ें (थाना, जनपद) → अपना नाम, भूमिका (CM / HM), PIN।
2. **स्टाफ:** अधिकारी / सिपाही की सूची (नाम, पद, मोबाइल) → हर एक का **6 अंकों का कोड** (उसे बताना है)।
3. **मुख्य screen:** टाइल — इस हफ़्ते आए / लंबित / तिथि निकल गई / इस माह पूरे (मालिक: "आज आए" की जगह "इस हफ़्ते आए"); "+ न्यायालय का कागज़", "+ प्रार्थना पत्र", नीचे सूची (filter: स्थिति / अधिकारी / प्रकार / तारीख; खोज)।
4. **नया काम:** fields भरें, फ़ोटो लें (camera / gallery), अधिकारी चुनें, भेजें।
5. **काम का विवरण:** सब fields, फ़ोटो, स्थिति की समय-रेखा, "दूसरे अधिकारी को दें" (re-allot), वापस लें।
6. **अधिकारी-वार:** हर अधिकारी पर कितने लंबित / निकले।

## 5. InvestSuite (अधिकारी) में बदलाव (चरण 1)
- Settings → **"थाने से जोड़ें"** → कोड डालें → "बछरावां थाना से जुड़ गए"।
- app खुलने / आगे आने पर और 🔔 push पर: नए काम आएँ → न्यायालय / प्रार्थना पत्र module में अपने आप जुड़ें (दोबारा न जुड़ें)।
- काम पर छोटा निशान "📥 कार्यालय से"; आख्या लगाने / पूरा होने पर स्थिति अपने आप वापस।
- internet न हो तो: बाद में भेज देगा (कुछ नहीं खोएगा)।
- जो अधिकारी थाने से नहीं जुड़ा, उसका app बिल्कुल अभी जैसा चलेगा।

## 6. तकनीकी ढाँचा (सार)
- **एक repo, दो APK:** InvestSuite + "InvestSuite कार्यालय" (अलग नाम, icon, package — एक फ़ोन में दोनों डल सकते हैं)।
  APK बनाते समय चुनना होगा कौन-सा।
- **Supabase (cloud):** tables — थाना, सदस्य (भूमिका, कोड), काम (प्रकार, fields, तिथियाँ), allot / स्थिति इतिहास, फ़ाइलें (फ़ोटो / PDF)।
  हर table पर ताला (RLS): हर सदस्य सिर्फ़ अपने थाने का, अधिकारी सिर्फ़ अपने को allot हुआ देखे।
- **Tables बनाना:** मैं SQL file दूँगा → मालिक Supabase के SQL Editor में paste → Run।
- **🔔 सूचना:** Expo की मुफ़्त push सेवा (app बंद हो तब भी)।
- **खर्च:** शुरू में शून्य (Supabase free)। उपयोग बढ़ने पर Supabase Pro।

  बीट सूचना · NCR · थाना प्रार्थना पत्र), प्राप्ति तिथि, अंतिम तिथि, मामला (matter), जाँचकर्ता का नाम, स्थिति (लंबित / निस्तारित / पूर्ण),
  निस्तारण तिथि; आवेदक (कई: नाम, पिता/पति, मोबाइल ×2, पता, गाँव, थाना, जनपद, उम्र, लिंग, जाति); विपक्षी (कई, वही + टिप्पणी);
  आख्या (report) + कार्यवाही (pp_actions). **फ़ोटो / PDF लगाने की जगह नहीं है।** बीट सूचना / NCR = "कार्यवाही" वाला रास्ता.
- **न्यायालय** (`nyayalay_documents`): पंजीकरण सं0, प्रकार (NBW · Summons · Bail (Lower Court) · High Court Documents · Anya),
  उप-प्रकार (Bail / Writ), writ (MB / CRLP / अन्य), न्यायालय, वाद सं0, अपराध सं0, धाराएँ, FIR सं0 / वर्ष / थाना, मामला, शीर्षक,
  अंतिम तिथि, स्थिति (लंबित / पूर्ण), चेकलिस्ट; व्यक्ति (अभियुक्त / अपीलार्थी: नाम, पिता, मोबाइल, पता, टिप्पणी); आख्या.
  **फ़ोटो / PDF की जगह यहाँ भी नहीं।**
- कार्यालय के "प्रकार" इन्हीं सूचियों से मिलाने होंगे (मालिक से पूछा — भाग 2c की सूची इनसे अलग है).
