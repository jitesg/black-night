## 1. कौन-कौन

| भूमिका | कौन | app | क्या करेगा |
|---|---|---|---|
| **कार्यालय मुंशी (CM)** | थाने का कार्यालय मुंशी | InvestSuite कार्यालय | कागज़ / प्रार्थना पत्र दर्ज करना, अधिकारी को allot करना, स्थिति देखना |
| **हेड मोहर्रिर (HM)** | हेड मोहर्रिर | InvestSuite कार्यालय | CM वाले सारे काम + आगे चलकर **मालगृह** (माल का रजिस्टर) |
| **अधिकारी** | उ0नि0 / निरीक्षक (विवेचक) | InvestSuite (अभी वाला) | allot हुआ काम अपने module में पाना, आख्या लगाना |
| **सिपाही** (चरण 3–4) | आरक्षी / मुख्य आरक्षी | कार्यालय app में "सिपाही" भूमिका | माँगी गई सूचना देना, अपनी ड्यूटी देखना |

*मान लिया है:* CM और HM दोनों काम 1–4 कर सकेंगे; मालगृह सिर्फ़ HM देखेगा (बाद का चरण)। मालिक बदलना चाहें तो बताएँ।

## 2. चार काम

### काम 1 — न्यायालय के कागज़ (चरण 1)
**कार्यालय में दर्ज होगा:**
- न्यायालय (चुनें: मा0 उच्च न्यायालय लखनऊ खंडपीठ / इलाहाबाद / जनपद न्यायालय… / अन्य)
- कागज़ का प्रकार: आख्या माँगी / बेल नोटिस / सम्मन / वारंट (NBW) / जमानत / अन्य
- वाद सं0, मु0अ0सं0, धारा, अभियुक्त / पक्षकार का नाम
- प्राप्ति तिथि, **नियत तिथि**
- कागज़ की फ़ोटो / PDF (एक या अधिक)
- टिप्पणी (वैकल्पिक)

**फिर:** "अधिकारी चुनें" → **allot करें**।

**अधिकारी के InvestSuite में:** 🔔 "न्यायालय से नया कागज़ — वाद सं0 … , नियत तिथि …"; न्यायालय module में नया काम **सारे fields भरे हुए**
और फ़ोटो साथ; अंतिम तिथि वाले alert (अभी जैसे — High Court 5/3/1/0 दिन पहले…) अपने आप लगेंगे।

### काम 2 — RL, जनता दर्शन, अन्य प्रार्थना पत्र (चरण 1)
**कार्यालय में दर्ज होगा:**
- कहाँ से आया: RL / जनता दर्शन / IGRS / SP कार्यालय / CO कार्यालय / थाना / अन्य
- संदर्भ / शिकायत सं0, प्राप्ति तिथि, **अंतिम तिथि**
- आवेदक (नाम, पिता/पति, पता, मोबाइल), विपक्षी (वैकल्पिक)
- विषय (छोटा), प्रार्थना पत्र की फ़ोटो / PDF
- टिप्पणी (वैकल्पिक)

**फिर:** अधिकारी चुनें → **दें**।

**अधिकारी के InvestSuite में:** 🔔 + प्रार्थना पत्र module में नया प्रार्थना पत्र, सब भरा हुआ; "रिपोर्ट लगाएं" / "प्रारूप से जोड़ें" पहले जैसे।

### काम 3 — ऊपर से माँगी सूचना (चरण 2)
1. **दर्ज:** किस कार्यालय ने माँगी (SP / ASP / CO / DCRB / अन्य), पत्रांक, क्या माँगा, भेजने की अंतिम तिथि, पत्र की फ़ोटो।
2. **मँगाना:** कार्यालय किन सिपाहियों / अधिकारियों से मँगाए (एक या कई) — हर एक के फ़ोन पर "सूचना चाहिए … तक"।
3. **जवाब:** वे अपने app में जवाब लिखें / फ़ोटो लगाएँ → कार्यालय में "3 में से 2 आए"।
4. **भेजना:** कार्यालय जवाब जोड़कर तैयार करे (एक जगह सब दिखेंगे), भेजे, और दर्ज करे: "भेजी — दिनांक … , किस माध्यम से"।

### काम 4 — ड्यूटी लगाना (चरण 2)
- तारीख, समय से–तक, ड्यूटी का प्रकार (बैंक / पिकेट / गश्त / यातायात / त्योहार / न्यायालय पैरवी / खजाना / अन्य), जगह
- कौन-कौन: सिपाही / मुख्य आरक्षी / होमगार्ड / PRD (सूची से चुनें; हथियार-कारतूस वैकल्पिक)
- जिसकी ड्यूटी लगी उसके फ़ोन पर सूचना; कार्यालय में "आज की ड्यूटी" सूची
- बाद में: इसी से GD की "रवानगी कर्मचारीगण … बेस प्वाइंट …" लाइन अपने आप बन सकती है (रवानगी के नमूने पहले से app में हैं)।

## 3. हर काम की स्थिति (कार्यालय को दिखेगी)

```
दर्ज ── allot ──► अधिकारी को मिला ──► देखा ──► आख्या लगी / पूरा      (हरा)
                                         └──► लंबित (तिथि बाकी)       (पीला)
                                         └──► तिथि निकल गई            (लाल)
```
- **अधिकारी से सिर्फ़ स्थिति वापस जाएगी** (देखा / आख्या लगी / पूरा + दिनांक)। आख्या का पूरा text, केस डायरी, मुकदमे का डाटा
  **फ़ोन में ही रहेगा**, cloud पर नहीं जाएगा।
- कार्यालय की मुख्य screen: आज आए / लंबित / तिथि निकली — अधिकारी-वार गिनती।

## 4. कार्यालय app की screens (चरण 1)

1. **पहली बार:** थाना जोड़ें (थाना, जनपद) → अपना नाम, भूमिका (CM / HM), PIN।
2. **स्टाफ:** अधिकारी / सिपाही की सूची (नाम, पद, मोबाइल) → हर एक का **6 अंकों का कोड** (उसे बताना है)।
3. **मुख्य screen:** "+ न्यायालय का कागज़", "+ प्रार्थना पत्र", नीचे सूची (filter: स्थिति / अधिकारी / प्रकार / तारीख; खोज)।
4. **नया काम:** fields भरें, फ़ोटो लें (camera / gallery), अधिकारी चुनें, भेजें।
5. **काम का विवरण:** सब fields, फ़ोटो, स्थिति की समय-रेखा, "दूसरे अधिकारी को दें" (re-allot), वापस लें।
6. **अधिकारी-वार:** हर अधिकारी पर कितने लंबित / निकले।

## 5. InvestSuite (अधिकारी) में बदलाव (चरण 1)
- Settings → **"थाने से जोड़ें"** → कोड डालें → "बछरावां थाना से जुड़ गए"।
- app खुलने / आगे आने पर और 🔔 push पर: नए काम आएँ → न्यायालय / प्रार्थना पत्र module में अपने आप जुड़ें (दोबारा न जुड़ें)।
- काम पर छोटा निशान "📥 कार्यालय से"; आख्या लगाने / पूरा होने पर स्थिति अपने आप वापस।
- internet न हो तो: बाद में भेज देगा (कुछ नहीं खोएगा)।
- जो अधिकारी थाने से नहीं जुड़ा, उसका app बिल्कुल अभी जैसा चलेगा।

## 6. तकनीकी ढाँचा (सार)
- **एक repo, दो APK:** InvestSuite + "InvestSuite कार्यालय" (अलग नाम, icon, package — एक फ़ोन में दोनों डल सकते हैं)।
  APK बनाते समय चुनना होगा कौन-सा।
- **Supabase (cloud):** tables — थाना, सदस्य (भूमिका, कोड), काम (प्रकार, fields, तिथियाँ), allot / स्थिति इतिहास, फ़ाइलें (फ़ोटो / PDF)।
  हर table पर ताला (RLS): हर सदस्य सिर्फ़ अपने थाने का, अधिकारी सिर्फ़ अपने को allot हुआ देखे।
- **Tables बनाना:** मैं SQL file दूँगा → मालिक Supabase के SQL Editor में paste → Run।
- **🔔 सूचना:** Expo की मुफ़्त push सेवा (app बंद हो तब भी)।
- **खर्च:** शुरू में शून्य (Supabase free)। उपयोग बढ़ने पर Supabase Pro।
